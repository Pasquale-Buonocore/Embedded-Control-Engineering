# Embedded Control Engineering Learning Roadmap

A progressive learning path in control engineering, sensor processing, and state estimation. Each lesson has its own Markdown file, which will be developed during study.

| Area | Lessons | Focus |
|---|---:|---|
| [Automatic Control](automatic-control/README.md) | 01–08 | Classical control and digital controllers |
| [PMSM Control Design](pmsm-control-design/README.md) | M01–M08 | PID intuition, controller tuning, and cascaded PMSM current, speed, and position loops |
| [Sensor and State Estimation](sensor-and-state-estimation/README.md) | 09–21 | Sensor data, filtering, and sensor fusion |
| [State-Space Control and Estimation](state-space-control-and-estimation/README.md) | 22–24 | LQR and state observers |

After lessons 01–08, the PMSM track can be studied directly for motor-drive control; the estimation and state-space tracks can follow as needed. Practical projects will be added to the relevant area when a lesson calls for one.
