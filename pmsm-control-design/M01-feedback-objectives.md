# Lesson M01 — What Should Feedback Achieve?

## Goal

Given a plant and a control requirement, state what feedback must improve and how success will be measured. Explain when P, I, or D action helps and what each action costs in control effort, noise sensitivity, or robustness.

## Topics

Tracking, disturbance rejection, steady-state error, rise and settling time, overshoot, stability margins, noise sensitivity, and control effort. Compare responses with and without each controller term.
