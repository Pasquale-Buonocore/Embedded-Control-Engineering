# State-Space Control and Estimation

Modern control and state estimation through LQR, Luenberger observers, and Kalman estimators.

Prerequisites: linear state-space models (`ẋ = Ax + Bu`, `y = Cx + Du`), eigenvalues, controllability, observability, state feedback, and basic covariance concepts. Future examples will use a generic state-space model.
